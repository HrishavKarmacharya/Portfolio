# Single-Page HTML CV

A single-page CV built with semantic HTML, SEO meta tags, Open Graph tags and a favicon, with a simple interactive CSS file.

**Project URL:** https://roadmap.sh/projects/single-page-cv

**Live demo:** [https://hrishavkarmacharya.github.io/Roadmap.sh-ProjectsHK/Frontend%20Projects/01-single-page-cv/](https://hrishavkarmacharya.github.io/Roadmap.sh-ProjectsHK/Frontend%20Projects/01-single-page-cv/)

![Single-page CV preview](../../assets/images/single-page-cv.png)

## Requirements covered

- [x] Semantic HTML structure
- [x] Single-page layout with skills, education and experience sections
- [x] SEO meta tags in the `<head>`
- [x] Open Graph tags for social sharing
- [x] Favicon linked in the `<head>`

## Features

- Semantic tags: `header`, `main`, `section`, `article`, `address`, `time`, `nav`, `footer`
- JSON-LD `Person` structured data
- Hover and keyboard-focus effects, automatic dark mode, reduced-motion support and print styles
