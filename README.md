# Hrishav Karmacharya | CV Portfolio

A single-page, semantic HTML CV for Hrishav Karmacharya, a BIM student and junior frontend developer based in Kathmandu, Nepal.

**Live site:** [https://hrishavkarmacharya.github.io/Portfolio/](https://hrishavkarmacharya.github.io/Portfolio/)

## About this project

This project builds a CV using clean, accessible HTML, with a simple CSS file (`style.css`) that adds a responsive layout and interactive hover and focus effects.

## Features

- **Semantic HTML:** `header`, `main`, `section`, `article`, `address`, `time`, `nav` and `footer`, with each section labelled by its heading.
- **Single-page layout:** Skills, Education, Experience and Across the Internet sections.
- **SEO meta tags:** title, description, keywords, author, robots, theme colour and canonical URL.
- **Open Graph and Twitter Card tags:** for rich previews when the link is shared on LinkedIn, Facebook, X and other platforms.
- **Structured data (JSON-LD):** a `Person` schema that helps search engines understand the page.
- **Interactive CSS:** skill chips and profile buttons lift on hover, entries highlight on hover and keyboard focus, and links get an animated underline.
- **Accessible and responsive:** visible keyboard focus, automatic dark mode, reduced-motion support, mobile layout and a clean print style.
- **Favicon:** an SVG icon linked in the `<head>`.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/HrishavKarmacharya/Portfolio.git
   ```
2. Open the folder:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` in any web browser. No build step or dependencies are needed.

## Deployment

The site is hosted on GitHub Pages from the `main` branch (root folder). Every push to `main` updates the live site within a minute or two.
